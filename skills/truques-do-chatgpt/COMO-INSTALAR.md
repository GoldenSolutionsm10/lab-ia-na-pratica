# Como instalar: 5 truques de foto no ChatGPT (/restaurar, /cabelo, /remover, /miniatura, /envelopar)

## Claude.ai ou Claude Desktop
1. Baixe `truques-do-chatgpt.zip` da pasta `zips` deste repositório.
2. Abra Configurações → Capacidades → Skills.
3. Envie o arquivo `.zip`, sem descompactar.
4. Confira se a skill aparece ligada.

## Claude Code
1. Descompacte o `.zip`.
2. Copie a pasta `truques-do-chatgpt` para `~/.claude/skills/` (todos os projetos) ou `.claude/skills/` (um projeto).
3. Abra uma sessão nova.

## ChatGPT
1. Abra o `SKILL.md` e copie o bloco "Cole isto nas instruções".
2. No ChatGPT: seu nome → Personalizar o ChatGPT (ou crie um Projeto e cole nas instruções dele).
3. Salve e mande `/restaurar` com uma foto para testar.

## Conferir
Pergunte: "Você tem a skill truques-do-chatgpt?". Depois, faça o primeiro pedido de `COMO-USAR.md`.

O menu do Claude pode mudar de nome com o tempo. Conferido em 23/11/2026.
