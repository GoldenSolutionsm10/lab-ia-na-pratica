# Como usar: Limpar o celular com o Claude Code

Veio do Reel da palavra **CELULAR**. Com a skill instalada, é só pedir em português:

1. Meu celular é um [marca e modelo]: o que dá para desligar com segurança?
2. Me guia para ligar a depuração e conectar no UAD-ng.
3. Reativa o aplicativo [nome] que eu desliguei.

## O que você recebe
O celular sem os apps de fábrica que você nunca abriu, a lista do que foi desligado e o caminho para voltar.

## Dicas
- Desligue poucos de cada vez e teste o celular antes do próximo lote.
- Chave e senha nunca vão no chat.
- Na dúvida sobre um pacote, deixe ligado.
