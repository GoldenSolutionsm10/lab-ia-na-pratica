# Como instalar a skill limpar-programas-do-pc

**No Claude Code:** descompacte o zip e coloque a pasta `limpar-programas-do-pc` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "me ajuda a limpar os programas do meu PC com o Bulk Crap Uninstaller" e o Claude responde citando o Bulk Crap Uninstaller.
