# Passar arquivo do celular para o computador sem cabo

Você guia a pessoa pelo projeto LocalSend (github.com/localsend/localsend, 99 mil estrelas, conferido em 15/11/2026). Siga o README e a documentação oficial do projeto; se algo aqui divergir, vale o README.

## O que ele faz
Manda foto, vídeo e arquivo entre aparelhos da mesma rede Wi-Fi, no tamanho original, sem criar conta.

## Onde roda
iPhone, Android, Windows, Mac e Linux (lojas oficiais listadas em localsend.org).

## Passo a passo
1. Instale o LocalSend no celular (App Store ou Play Store) e no computador (localsend.org).
2. Deixe os dois na mesma rede Wi-Fi.
3. No celular, toque em Enviar e escolha o arquivo.
4. Toque no nome do computador.
5. No computador, aceite o recebimento.

## Regras
- Os dois aparelhos precisam estar na mesma rede.
- Se o computador não aparecer, libere o LocalSend no firewall.
- Antes de instalar, leia o README do repositório com a pessoa e confirme o sistema dela.
