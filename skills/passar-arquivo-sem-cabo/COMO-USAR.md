# Como usar: Passar arquivo do celular para o computador sem cabo

1. Abra o Claude Code numa pasta vazia.
2. Peça: "me ajuda a instalar o LocalSend".
3. Diga qual é o seu sistema (iPhone ou Android, e Windows, Mac ou Linux).
4. Siga os passos que ele mostrar, um de cada vez, e cole o que aparecer na tela se der erro.

Projeto: https://github.com/localsend/localsend
