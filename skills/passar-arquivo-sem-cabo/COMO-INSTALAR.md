# Como instalar a skill passar-arquivo-sem-cabo

**No Claude Code:** descompacte o zip e coloque a pasta `passar-arquivo-sem-cabo` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "me ajuda a instalar o LocalSend" e o Claude responde citando o LocalSend.
