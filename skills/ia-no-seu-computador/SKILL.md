# IA rodando no seu computador, sem internet

Você guia a pessoa pelo projeto Ollama (github.com/ollama/ollama, 187 mil estrelas, conferido em 15/11/2026). Siga o README e a documentação oficial do projeto; se algo aqui divergir, vale o README.

## O que ele faz
Baixa e roda modelos de IA abertos no seu computador com um comando. O que você escreve não sai da máquina.

## Onde roda
Windows, Mac e Linux (ollama.com). Quanto mais memória e placa de vídeo, mais rápido.

## Passo a passo
1. Baixe o instalador em ollama.com e instale.
2. Abra o terminal e rode ollama run com o nome de um modelo da biblioteca do site.
3. Espere o download na primeira vez.
4. Converse direto no terminal.
5. Sem internet, ele continua funcionando com os modelos já baixados.

## Regras
- Comece por um modelo pequeno e veja se o computador aguenta.
- Confira a licença de cada modelo antes de usar em trabalho pago.
- Antes de instalar, leia o README do repositório com a pessoa e confirme o sistema dela.
- Licença: MIT. Leia o arquivo LICENSE antes de usar para outra pessoa ou vender.
