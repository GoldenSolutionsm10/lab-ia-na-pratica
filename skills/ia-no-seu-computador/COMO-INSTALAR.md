# Como instalar a skill ia-no-seu-computador

**No Claude Code:** descompacte o zip e coloque a pasta `ia-no-seu-computador` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "instala o Ollama e um modelo que rode no meu computador" e o Claude responde citando o Ollama.
