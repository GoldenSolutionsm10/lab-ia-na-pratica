# Como instalar a skill limpar-o-email

**No Claude Code:** descompacte o zip e coloque a pasta `limpar-o-email` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "me ajuda a configurar o Inbox Zero no meu Gmail" e o Claude responde citando o Inbox Zero.
