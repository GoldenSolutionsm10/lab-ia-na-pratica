# Como usar: Limpar o e-mail e cancelar propaganda

1. Abra o Claude Code numa pasta vazia.
2. Peça: "me ajuda a configurar o Inbox Zero no meu Gmail".
3. Diga qual é o seu sistema (Gmail ou Outlook).
4. Siga os passos que ele mostrar, um de cada vez, e cole o que aparecer na tela se der erro.
