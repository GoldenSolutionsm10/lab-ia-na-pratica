# Como instalar a skill foto-antiga-nitida

**No Claude Code:** descompacte o zip e coloque a pasta `foto-antiga-nitida` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "instala o Upscayl e melhora as minhas fotos antigas" e o Claude responde citando o Upscayl.
