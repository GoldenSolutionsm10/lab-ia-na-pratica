# Como instalar: Atendente de IA que responde à meia-noite

## Claude.ai ou Claude Desktop
1. Baixe `atendente-24h-whatsapp.zip` da pasta `zips` deste repositório.
2. Abra Configurações → Capacidades → Skills.
3. Envie o arquivo `.zip`, sem descompactar.
4. Confira se a skill aparece ligada.

## Claude Code
1. Descompacte o `.zip`.
2. Copie a pasta `atendente-24h-whatsapp` para `~/.claude/skills/` (todos os projetos) ou `.claude/skills/` (um projeto).
3. Abra uma sessão nova.

## Conferir
Pergunte: "Você tem a skill atendente-24h-whatsapp?". Depois, faça o primeiro pedido de `COMO-USAR.md`.

O menu do Claude pode mudar de nome com o tempo. Conferido em 05/11/2026.
