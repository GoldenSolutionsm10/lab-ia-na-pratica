# Como instalar: Pasta de skills por área

## Claude.ai ou Claude Desktop
1. Baixe `pasta-de-skills.zip` da pasta `zips` deste repositório.
2. Abra Configurações → Capacidades → Skills (o "personalizar skills" do Reel).
3. Envie o arquivo `.zip`, sem descompactar.
4. Faça o mesmo com o `.zip` de cada skill da pasta que você quiser usar.

## Claude Code
1. Descompacte o `.zip`.
2. Copie a pasta `pasta-de-skills` para `~/.claude/skills/` (todos os projetos) ou `.claude/skills/` (um projeto).
3. Abra uma sessão nova.

## Conferir
Pergunte: "Você tem a skill pasta-de-skills?". Depois, faça o primeiro pedido de `COMO-USAR.md`.

O menu do Claude pode mudar de nome com o tempo. Conferido em 08/11/2026.
