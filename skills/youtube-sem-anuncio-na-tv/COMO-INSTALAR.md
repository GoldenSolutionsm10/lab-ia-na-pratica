# Como instalar a skill youtube-sem-anuncio-na-tv

**No Claude Code:** descompacte o zip e coloque a pasta `youtube-sem-anuncio-na-tv` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "instala o SmartTube na minha TV" e o Claude responde citando o SmartTube.
