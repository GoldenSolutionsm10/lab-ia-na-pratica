# Como usar: YouTube sem anúncio na TV

1. Abra o Claude Code numa pasta vazia.
2. Peça: "instala o SmartTube na minha TV".
3. Diga qual é o seu sistema (TV Android, Google TV ou Fire TV).
4. Siga os passos que ele mostrar, um de cada vez, e cole o que aparecer na tela se der erro.

Projeto: https://github.com/yuliskov/SmartTube
