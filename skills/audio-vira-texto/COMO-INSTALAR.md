# Como instalar a skill audio-vira-texto

**No Claude Code:** descompacte o zip e coloque a pasta `audio-vira-texto` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "instala o Buzz e transcreve este áudio" e o Claude responde citando o Buzz.
