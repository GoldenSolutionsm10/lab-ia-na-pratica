# Como usar: Criar jogos com o Claude

Veio do Reel da palavra **GAME**. Com as skills instaladas, é só pedir em português:

1. Quero criar um jogo de plataforma 2D no navegador: por onde começo?
2. Coloca pulo duplo no meu personagem do Godot.
3. Faz um inventário para o meu RPG na Unity.
4. Cria um labirinto que muda a cada partida.
5. Como eu exporto esse jogo para jogar no celular?

O router escolhe sozinho as skills certas para a sua engine e o seu pedido.

## O que você recebe
O jogo crescendo passo a passo, com código organizado e o mesmo estilo visual do começo ao fim.

## Dicas
- Comece pequeno: um personagem andando antes de fases, menu e loja.
- Um pedido por vez; teste antes do próximo.
- Use arte e personagens próprios.
