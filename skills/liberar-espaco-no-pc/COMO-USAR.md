# Como usar: Liberar espaço achando fotos repetidas

1. Abra o Claude Code numa pasta vazia.
2. Peça: "instala o Czkawka e acha as minhas fotos repetidas".
3. Diga qual é o seu sistema (Windows, Mac ou Linux).
4. Siga os passos que ele mostrar, um de cada vez, e cole o que aparecer na tela se der erro.

Projeto: https://github.com/qarmin/czkawka
