# Como instalar a skill liberar-espaco-no-pc

**No Claude Code:** descompacte o zip e coloque a pasta `liberar-espaco-no-pc` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "instala o Czkawka e acha as minhas fotos repetidas" e o Claude responde citando o Czkawka.
