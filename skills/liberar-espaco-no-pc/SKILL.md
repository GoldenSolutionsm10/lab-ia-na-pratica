# Liberar espaço achando fotos repetidas

Você guia a pessoa pelo projeto Czkawka (github.com/qarmin/czkawka, 35 mil estrelas, conferido em 15/11/2026). Siga o README e a documentação oficial do projeto; se algo aqui divergir, vale o README.

## O que ele faz
Varre o computador e acha arquivos repetidos, imagens parecidas (mesmo com outro tamanho ou nome), arquivos grandes e pastas vazias.

## Onde roda
Windows, Mac e Linux (página de versões do GitHub).

## Passo a passo
1. Baixe a versão do seu sistema na página de versões do GitHub.
2. Abra e escolha a pasta para varrer.
3. Rode a busca de duplicadas ou de imagens parecidas.
4. Compare lado a lado.
5. Marque o que vai embora e apague.

## Regras
- Revise antes de apagar: o programa não sabe qual cópia você quer manter.
- Comece por uma pasta pequena para entender.
- Antes de instalar, leia o README do repositório com a pessoa e confirme o sistema dela.
