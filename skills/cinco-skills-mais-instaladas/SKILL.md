# As 5 skills mais instaladas do Claude Code

Você guia a pessoa pelas 5 skills do ranking (repositórios conferidos em 12/11/2026). O número de instalações muda todo dia: confira no site skills.sh.

| Lugar | Skill | Repositório | Para quê |
|---|---|---|---|
| 1 | Find Skills | github.com/vercel-labs/skills (MIT) | Você diz o que quer fazer e ela procura e instala a skill certa |
| 2 | Hyperframes | github.com/heygen-com/hyperframes (Apache-2.0) | Vídeo com animação e legenda feito em código |
| 3 | Agent Browser | github.com/vercel-labs/agent-browser (Apache-2.0) | O Claude abre o navegador, clica e preenche |
| 4 | Grilling | github.com/mattpocock/skills (MIT) | Faz perguntas até entender o pedido antes de começar |
| 5 | Design Taste Frontend | github.com/Leonxlnx/taste-skill (MIT) | Tira a cara genérica dos sites feitos com IA |

## Passo a passo
1. Comece pela Find Skills, como o README dela indica.
2. Instale as outras uma por vez, pelo README de cada uma.
3. Teste cada skill com um pedido pequeno antes da próxima.

## Regras
- Leia o README e a licença antes de instalar.
- Antes de instalar skill de desconhecido, passe um verificador de código malicioso.
