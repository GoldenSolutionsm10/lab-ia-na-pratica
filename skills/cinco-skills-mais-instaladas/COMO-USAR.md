# Como usar: As 5 skills mais instaladas do Claude Code

Veio do Reel da palavra **SKILLS**. Com a skill instalada, é só pedir em português:

1. Instala a Find Skills e procura uma skill para [tarefa].
2. Instala as 5 do ranking, uma por vez.
3. Me diz qual usar primeiro para o meu trabalho de [área].

## O que você recebe
As 5 skills instaladas e quando usar cada uma.

## Dicas
- Um pedido por vez e confira o resultado antes do próximo.
- Chave e senha nunca vão no chat.
