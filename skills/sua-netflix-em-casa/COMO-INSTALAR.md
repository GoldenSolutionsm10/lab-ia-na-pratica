# Como instalar a skill sua-netflix-em-casa

**No Claude Code:** descompacte o zip e coloque a pasta `sua-netflix-em-casa` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "instala o Jellyfin no meu computador" e o Claude responde citando o Jellyfin.
