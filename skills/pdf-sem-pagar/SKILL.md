# Mexer em PDF sem pagar

Você guia a pessoa pelo projeto Stirling-PDF (github.com/Stirling-Tools/Stirling-PDF, 96 mil estrelas, conferido em 15/11/2026). Siga o README e a documentação oficial do projeto; se algo aqui divergir, vale o README.

## O que ele faz
Junta, separa, gira, comprime, assina e transforma PDF escaneado em texto (OCR), tudo no seu computador.

## Onde roda
Windows, Mac e Linux, pelo aplicativo de desktop ou por Docker (site oficial stirling.com).

## Passo a passo
1. Veja no README qual é a forma recomendada hoje (aplicativo de desktop ou Docker).
2. Instale pela forma escolhida.
3. Abra a ferramenta e arraste o PDF.
4. Escolha a ação: juntar, separar, comprimir, assinar ou OCR.
5. Baixe o arquivo pronto.

## Regras
- Documento sigiloso: use a versão instalada no seu computador, não a versão on-line de demonstração.
- Antes de instalar, leia o README do repositório com a pessoa e confirme o sistema dela.
- Licença: veja o LICENSE do repositório (tem parte aberta e parte paga). Leia o arquivo LICENSE antes de usar para outra pessoa ou vender.
