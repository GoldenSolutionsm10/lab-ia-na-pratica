# Como instalar a skill pdf-sem-pagar

**No Claude Code:** descompacte o zip e coloque a pasta `pdf-sem-pagar` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "instala o Stirling-PDF no meu computador" e o Claude responde citando o Stirling-PDF.
