# Como usar: O seu Google Fotos em casa

1. Abra o Claude Code numa pasta vazia.
2. Peça: "instala o Immich num computador da minha casa".
3. Diga qual é o seu sistema (Windows, Mac ou Linux, e iPhone ou Android).
4. Siga os passos que ele mostrar, um de cada vez, e cole o que aparecer na tela se der erro.

Projeto: https://github.com/immich-app/immich
