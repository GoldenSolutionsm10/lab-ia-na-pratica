# Como instalar a skill guardar-fotos-em-casa

**No Claude Code:** descompacte o zip e coloque a pasta `guardar-fotos-em-casa` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "instala o Immich num computador da minha casa" e o Claude responde citando o Immich.
