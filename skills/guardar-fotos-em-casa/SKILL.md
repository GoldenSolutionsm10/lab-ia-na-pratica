# O seu Google Fotos em casa

Você guia a pessoa pelo projeto Immich (github.com/immich-app/immich, 119 mil estrelas, conferido em 15/11/2026). Siga o README e a documentação oficial do projeto; se algo aqui divergir, vale o README.

## O que ele faz
Backup automático das fotos do celular para um computador da sua casa, com rosto, pessoas e busca por conteúdo (praia, cachorro).

## Onde roda
Servidor por Docker num computador que fica ligado (immich.app). Aplicativo para iPhone e Android.

## Passo a passo
1. Instale o Docker no computador que vai guardar as fotos.
2. Siga o guia de instalação com Docker Compose do site immich.app.
3. Abra o endereço no navegador e crie o usuário.
4. Instale o aplicativo Immich no celular e conecte no endereço.
5. Ligue o backup automático.

## Regras
- Tenha uma segunda cópia das fotos: um computador só não é backup.
- O computador precisa ficar ligado para o celular mandar as fotos.
- Antes de instalar, leia o README do repositório com a pessoa e confirme o sistema dela.
