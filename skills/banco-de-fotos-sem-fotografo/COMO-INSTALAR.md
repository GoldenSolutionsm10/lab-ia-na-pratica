# Como instalar: Banco de fotos suas sem fotógrafo

## Claude.ai ou Claude Desktop
1. Baixe `banco-de-fotos-sem-fotografo.zip` da pasta `zips` deste repositório.
2. Abra Configurações → Capacidades → Skills.
3. Envie o arquivo `.zip`, sem descompactar.
4. Confira se a skill aparece ligada.

## Claude Code
1. Descompacte o `.zip`.
2. Copie a pasta `banco-de-fotos-sem-fotografo` para `~/.claude/skills/` (todos os projetos) ou `.claude/skills/` (um projeto).
3. Abra uma sessão nova.

## Conferir
Pergunte: "Você tem a skill banco-de-fotos-sem-fotografo?". Depois, faça o primeiro pedido de `COMO-USAR.md`.

O menu do Claude pode mudar de nome com o tempo. Conferido em 05/11/2026.
