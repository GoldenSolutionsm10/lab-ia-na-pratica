# Como instalar a skill bloquear-propaganda-da-casa

**No Claude Code:** descompacte o zip e coloque a pasta `bloquear-propaganda-da-casa` em `~/.claude/skills/` (ou em `.claude/skills/` dentro do seu projeto). Abra o Claude Code de novo.

**No Claude.ai:** Configurações → Capacidades → Skills → enviar o zip.

Pronto quando: você pede "instala o Pi-hole num computador velho" e o Claude responde citando o Pi-hole.
