# Como usar: Bloquear propaganda em todo aparelho da casa

1. Abra o Claude Code numa pasta vazia.
2. Peça: "instala o Pi-hole num computador velho".
3. Diga qual é o seu sistema (Linux ou Raspberry Pi).
4. Siga os passos que ele mostrar, um de cada vez, e cole o que aparecer na tela se der erro.
