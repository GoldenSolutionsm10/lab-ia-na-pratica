# Como instalar: Agendar a semana de Reels sozinho

## Claude.ai ou Claude Desktop
1. Baixe `agendar-reels-sozinho.zip` da pasta `zips` deste repositório.
2. Abra Configurações → Capacidades → Skills.
3. Envie o arquivo `.zip`, sem descompactar.

## Claude Code
1. Descompacte o `.zip`.
2. Copie a pasta `agendar-reels-sozinho` para `~/.claude/skills/`.
3. Abra uma sessão nova.

Para a fila rodar sozinha, o Claude Code precisa de acesso ao seu servidor (SSH). Conferido em 05/11/2026.
