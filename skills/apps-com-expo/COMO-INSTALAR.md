# Como instalar: Apps com as skills da Expo

## Claude.ai ou Claude Desktop
1. Baixe `apps-com-expo.zip` da pasta `zips` deste repositório.
2. Abra Configurações → Capacidades → Skills.
3. Envie o arquivo `.zip`, sem descompactar.
4. Confira se a skill aparece ligada.

## Claude Code
1. Descompacte o `.zip`.
2. Copie a pasta `apps-com-expo` para `~/.claude/skills/` (todos os projetos) ou `.claude/skills/` (um projeto).
3. Abra uma sessão nova e instale também as skills oficiais pelo README de github.com/expo/skills.

## Conferir
Pergunte: "Você tem a skill apps-com-expo?". Depois, faça o primeiro pedido de `COMO-USAR.md`.

O menu do Claude pode mudar de nome com o tempo. Conferido em 12/11/2026.
