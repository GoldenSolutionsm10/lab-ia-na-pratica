# Guia · O Claude agora cuida do seu Instagram

**Jogue o guia no celular:** https://claude.ai/artifact/5JhTzwfHWSFa5TRrYE6TCh
**Prefere baixar?** [guia-instagram-com-claude.pdf](guia-instagram-com-claude.pdf) (13 páginas, o mesmo conteúdo)

Passo a passo em 8 fases para instalar a skill de Instagram no Claude e usar para escrever posts, responder comentários, arrumar o perfil, planejar a semana e achar o que está viralizando no seu nicho.

| Fase | O que você faz |
|---|---|
| 1 Instalar | Cola o link da skill no Claude (uma vez só) |
| 2 Sua voz | Ensina o seu jeito de falar com 3 Reels seus (uma vez só) |
| 3 a 8 | Posts, comentários, perfil, semana, viral e postar (toda semana) |

## Instalar a skill
- **No Claude (app ou site):** abra uma conversa nova, cole `https://github.com/Jakeschincariol/instagram-agent-skill` e peça: "Instale essa skill e confirme que o /ig-reel está funcionando."
- **No Claude Code:**
  ```
  /plugin marketplace add Jakeschincariol/instagram-agent-skill
  /plugin install instagram-agent
  ```
