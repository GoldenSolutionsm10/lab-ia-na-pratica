## Como usar
**Claude.ai:** Configurações → Capacidades → Skills → enviar o `.zip`. Nas skills de base, compacte a pasta antes.
**Claude Code:** copie a pasta da skill para `~/.claude/skills/` (ou `.claude/skills/` do seu projeto).
Depois é só pedir em português. Cada `.zip` traz exemplos em `COMO-USAR.md`.

Ferramentas de terceiros têm licença própria: leia o README de cada uma antes de instalar.
