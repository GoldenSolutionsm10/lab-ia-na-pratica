# Lab IA na Prática · skills abertas

Skills grátis para usar no Claude (Claude.ai, Claude Code ou qualquer agente que leia `SKILL.md`). Pare de estudar IA. Comece a usar.

| Skill | Para quê |
|---|---|
| [copy-de-conteudo](skills/copy-de-conteudo/SKILL.md) | Roteiro de Reels, carrossel, post estilo X, story e legenda com gancho, corpo e CTA por etapa do funil |
| [posicionamento-nas-redes](skills/posicionamento-nas-redes/SKILL.md) | Diagnóstico de marca e posicionamento: frase central, arquétipo, narrativa, bio e destaques |
| [ache-seu-publico-alvo](skills/ache-seu-publico-alvo/SKILL.md) | PRD de público e concorrentes: dores reais, quem já fala com ele e as brechas para entrar |

## Como usar
**Claude.ai:** Configurações → Capacidades → Skills → enviar a pasta da skill compactada em `.zip`.
**Claude Code:** copie a pasta para `~/.claude/skills/` (ou `.claude/skills/` do seu projeto).
Depois é só pedir: "faz a copy de um Reels sobre ...", "monta meu posicionamento", "acha meu público-alvo".

Ordem sugerida: **público → posicionamento → copy**.
